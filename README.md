# Сайт статей из Markdown

Каждый `.md` файл в папке `content/articles` превращается в отдельную статью со своей ссылкой.
Сайт собирается и публикуется автоматически бесплатно через GitHub Pages.

## Первый запуск (один раз, ~10 минут)

1. Зарегистрируйтесь на [github.com](https://github.com).
2. Создайте репозиторий: **New repository** → имя `ВАШ-ЛОГИН.github.io` → **Public** → **Create**.
   (С таким именем сайт будет по адресу `https://ВАШ-ЛОГИН.github.io`.)
3. На странице репозитория: **Add file → Upload files** и перетащите **всё содержимое** этой папки,
   включая папку `.github` (в ней инструкция для автоматической публикации). Нажмите **Commit changes**.
   > На Windows папка `.github` видна как обычная. Если её нет в списке загруженных — создайте файл вручную:
   > **Add file → Create new file**, имя `.github/workflows/hugo.yml`, вставьте содержимое из архива.
4. **Settings → Pages → Build and deployment → Source: GitHub Actions**.
5. Откройте вкладку **Actions** — через 1–2 минуты появится зелёная галочка, сайт опубликован.

## Как добавить статью

1. Откройте папку `content/articles` в репозитории.
2. **Add file → Upload files** → перетащите `.md` файл → **Commit changes**.
3. Через минуту статья на сайте. Адрес = имя файла: `moya-statya.md` → `https://сайт/moya-statya/`.

Имена файлов лучше писать латиницей через дефис. Шапка файла:

```yaml
---
title: "Название статьи"
date: 2026-10-01
description: "Краткое описание — видно в списке и в превью ссылки в Telegram/WhatsApp."
tags: ["энергетика", "ветер"]
---
```

Если у файла нет шапки, статья не получит заголовок и дату — добавьте хотя бы `title` и `date`.
Черновик: `draft: true` — такая статья не публикуется.

Редактировать можно прямо на GitHub: откройте файл → значок карандаша → **Commit changes**.

## Поддерживается

- Markdown: заголовки, списки, таблицы, цитаты, ссылки, картинки
- формулы LaTeX: `$...$` в строке и `$$...$$` блоком (обычный знак доллара — `\$`)
- подсветка кода с кнопкой «Копировать»
- светлая и тёмная тема, оглавление для длинных статей
- кнопки «Поделиться», «Копировать ссылку», Telegram, WhatsApp
- превью ссылок в мессенджерах, RSS, карта сайта для поисковиков

Картинки: положите в `static/images/` и вставьте `![Подпись](/images/файл.jpg)`.
Своё превью для статьи: `image: "images/файл.jpg"` в шапке.

## Настройки

Название сайта, имя автора и описание — в файле `hugo.toml`. Текст на главной — в `content/_index.md`.

## Свой домен

1. Купите домен у регистратора (например, INWX, Porkbun, Namecheap, Cloudflare).
2. В DNS-настройках домена добавьте записи:

   | Тип | Имя | Значение |
   |---|---|---|
   | A | @ | 185.199.108.153 |
   | A | @ | 185.199.109.153 |
   | A | @ | 185.199.110.153 |
   | A | @ | 185.199.111.153 |
   | CNAME | www | ВАШ-ЛОГИН.github.io |

3. На GitHub: **Settings → Pages → Custom domain** → впишите домен → **Save**.
   Когда проверка пройдёт, включите **Enforce HTTPS**.
4. Готово: ссылки на статьи автоматически станут вида `https://ваш-домен.de/moya-statya/`.

DNS обновляется от нескольких минут до суток.

## Просмотр на своём компьютере (необязательно)

Установите [Hugo extended](https://gohugo.io/installation/) и выполните `hugo server` в этой папке —
сайт откроется на `http://localhost:1313` и будет обновляться при каждом сохранении файла.
