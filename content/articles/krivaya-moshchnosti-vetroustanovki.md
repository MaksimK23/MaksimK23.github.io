## Мощность ветрового потока

Кинетическая мощность воздуха, проходящего через ометаемую площадь ротора \(A\), растёт пропорционально кубу скорости ветра:

$$
P_\text{ветра} = \frac{1}{2}\,\rho\,A\,v^3
$$

где \(\rho \approx 1{,}225\ \text{кг/м}^3\) — плотность воздуха при нормальных условиях, а \(v\) — скорость ветра. Удвоение скорости даёт в восемь раз больше мощности.

## Предел Бетца

Турбина не может забрать всю энергию потока: воздух за ротором должен продолжать движение. Максимальный коэффициент мощности

$$
C_{p,\max} = \frac{16}{27} \approx 0{,}593
$$

Реальные современные установки достигают \(C_p\) около 0,45–0,50 в оптимальной точке.

## Характерные участки кривой

| Участок | Скорость ветра | Что происходит |
|---|---|---|
| Ниже скорости включения | < 3 м/с | Ротор стоит, выработки нет |
| Рост мощности | 3–12 м/с | Мощность растёт примерно как \(v^3\) |
| Номинальная мощность | 12–25 м/с | Лопасти поворачиваются, мощность постоянна |
| Выше скорости отключения | > 25 м/с | Турбина останавливается для защиты |

## Расчёт на Python

```python
import numpy as np

rho = 1.225          # кг/м³
D = 120              # диаметр ротора, м
A = np.pi * D**2 / 4
P_rated = 3.6e6      # номинальная мощность, Вт

def power(v, cp=0.45):
    """Упрощённая кривая мощности турбины."""
    p = 0.5 * rho * A * v**3 * cp
    p = np.where(v < 3, 0, np.minimum(p, P_rated))
    return np.where(v > 25, 0, p)

print(power(np.array([2, 6, 10, 14, 26])) / 1e6)  # МВт
```

## Итог

Кривая мощности — главный паспортный документ ветроустановки. Вместе с распределением скоростей ветра на площадке (обычно распределение Вейбулла) она позволяет оценить годовую выработку и коэффициент использования установленной мощности.
